## TSRun, the emulator

The game runs in the browser on [TSRun](https://github.com/josef-jelinek/TSRun), the Timex Sinclair 2068 emulator written by **Josef Jelínek** ([josef-jelinek](https://github.com/josef-jelinek)). This repository pins a [fork](https://github.com/nchiker/TSRun) as the `tsrun/` git submodule; the fork adds a Kempston mouse and a host file bridge (ports `$6F` / `$6D`) that the Imp Doom III save and load use. The emulator itself is Josef's. TSRun carries no licence file of its own, so it is referenced as a submodule and not copied into this repository.

## The Timex Sinclair 2068 and its ROMs

The computer itself: the **TS2068** by Timex Computer Corporation, descended from the Sinclair ZX Spectrum by **Sir Clive Sinclair** and Sinclair Research. The page loads TSRun's stock TS2068 ROMs (`tsrun/roms/ts2068-0.rom` and `ts2068-1.rom`), which TSRun's `roms/README.md` describes as partly released by Amstrad for non-commercial use and partly abandonware "as far as I could verify". Timex, Sinclair and ZX Spectrum are trademarks of their owners. This is an independent community project, not affiliated with Timex, Sinclair, Amstrad, Apple, Fuse or ZEsarUX.

## The sibling projects

Imp Doom is built with the author's other TS2068 projects (**nchiker**):

- [Leap IDE and Leap Arcade](https://github.com/nchiker/2068-Leap-IDE): the website's layout, colour variables and theme toggle follow that project's pages, and its `tsrun/` submodule pin is the one used here.
- [Leap Desktop](https://github.com/nchiker/2068-Leap-Desktop): `js/fshost.js` is that project's `web/fshost.js` (the host side of the file bridge, MIT, same author), and `js/play.js` is modelled on its `web/main.js` test page.

## Built with Claude Code

Much of the code, the tests and the documentation were written with **Claude Code** (Claude, by [Anthropic](https://www.anthropic.com)) working under nchiker's direction, with nchiker reviewing, choosing and approving the results. The game's tunes were generated by the project's own tools and the final choice of which build to ship is the owner's.

## Tools it was built and tested with

- [SjASMPlus](https://github.com/z00m128/sjasmplus) assembles the Z80 code; [Node.js](https://nodejs.org) runs the tests and tools.
- [ffmpeg](https://ffmpeg.org) converts the tunes to MP3 for this site.
- GitHub Pages hosts the site.
